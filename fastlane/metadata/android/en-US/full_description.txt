A resizable home-screen widget that compares yesterday's weather predictions against what actually happened.

Please note: This is a personal hobby project and has not been thoroughly tested across all devices. You may encounter sizing issues or bugs. Feedback and bug reports are very welcome!

FORECAST vs. ACTUAL
• Displays predicted temperature ranges alongside actual measured ranges from local weather stations
• Browse up to 30 days of history with the widget's navigation arrows
• Tracks accuracy statistics: average error, bias, and days within ±3°F
• Inspect forecast evolution: see how the prediction for a given day changed over time

WEATHER SOURCES
• National Weather Service (US) and Open-Meteo (worldwide) are built in (no API keys required)
• Option to configure other API keys (Silurian, Tomorrow.io, WeatherAPI, Visual Crossing, etc.) in settings
• Tap the source name on the widget to switch and compare forecasts

BATTERY-CONSCIOUS SYNCING
• Updates displayed temperature from cache with minimal background wakeups
• Network fetches automatically scale back as battery drains
• Interpolates current temperatures smoothly from hourly forecasts

DETAILS
• Tap days for hourly temperature curves, rain chances, and cloud cover
• Customizable location modes (follow device location, search, or pin coordinates manually)
• Fits various launcher layouts, adjusting from a single cell up to a full strip

No ads. No accounts. Location data is only used to fetch weather forecasts for your coordinates.
